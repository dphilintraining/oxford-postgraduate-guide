# The Unofficial Oxford Postgraduate Guide, 2027 entry revision

Open `index.html` to browse the site locally, or open `funding.html` to use the funding explorer. No account or external service is required.

This is an independent draft website for prospective Oxford postgraduate applicants. It is **not** endorsed by the University of Oxford, and the directory is non-exhaustive. Check official provider links for binding information.

## What's new

- 71 live 2027 funding entries spanning University, college, department and external programmes; 38 are checked against individual official sources.
- A complete audit CSV and Markdown report covering all 42 original entries, the 11 subsequent additions, and four new programmes; the archived entry is listed separately.
- Explicit checked-versus-unchecked labels for each entry; no blanket source-verification claim.
- Date-aware filtering and sorting only when a confirmed fixed date applies.
- Closed-cycle notices, updated UK funding FAQ, and DPhil personal-content sections.
- Reset and initial sort both use closest dated deadline.
- Existing illustrative homepage hero image preserved, as requested.
